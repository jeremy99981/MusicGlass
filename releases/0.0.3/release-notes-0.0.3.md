# MusicGlass 0.0.3

Cette version affine les interactions du lecteur iOS, avec un gros focus sur le comportement natif.

## iOS

- Correction du geste vertical sur la pochette du full player : le lecteur suit maintenant le doigt pendant le swipe vers le bas.
- Conservation du swipe horizontal sur la pochette : gauche vers droite pour précédent, droite vers gauche pour suivant.
- Amélioration de la cohérence du comportement Liquid Glass entre la pochette et le reste du full player.
- Mise à jour version iOS : `0.0.3` build `3`.

## Builds inclus

- `MusicGlass-0.0.3-unsigned.ipa` : IPA iOS non signée.
